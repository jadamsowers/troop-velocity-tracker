Log in another way

If the form above doesn't work (for example, if you sign in with Apple, Google, or a scouting.org SSO account), grab the token manually:

  1. Open advancements.scouting.org in a new tab and sign in normally.
  2. Open your browser's developer tools (F12) → Console tab.
  3. Paste this and press Enter:
JSON.stringify({token: JSON.parse(localStorage.LOGIN_DATA).token})

Copy the resulting JSON string (with quotes) and paste it into Troop Velocity Tracker's token field.
